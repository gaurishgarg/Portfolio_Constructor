AR scene (visiting card)

What appears when someone scans your visiting card (ar.html). Until you save something here, MindAR's demo scene is used. Make the .mind file from your card artwork with the MindAR image compiler; the model is best as a single .glb file (keep it small, a few MB). Position, rotation and size are measured in card widths: the card is 1 wide, so 0 0.1 0 is a tenth of a card width up.
